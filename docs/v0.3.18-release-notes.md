# MangoMe v0.3.18 — Bounded User-Intent Execution Authority

MangoMe v0.3.18 narrows one authority boundary that made ordinary work unnecessarily dependent on an external controller.

An explicit current user request may now admit bounded task-scoped `EXECUTE` work in a workspace that already contains canonical MangoMe state. Recovered state by itself still grants no authority.

The release does not relax independent verification, normative mutation, control, owner acceptance, or routing authority. Those transitions keep their existing capability checks.

There is no persistence-schema or MongoDB migration in this release.

The change is intentionally limited to ordinary execution admission and is covered by focused regression tests. Raw evaluation evidence and deployment-specific diagnostics are not part of the public release artifact.
