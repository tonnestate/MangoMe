# MangoMe v0.3.19 — Compact Human Folder Status

v0.3.19 adds a bounded, display-only human status projection for ordinary MangoMe operation.

The normal seven-tool worker surface is unchanged. A worker can request the compact view through the existing workspace status path with `human=true`.

The projection is intentionally small and deterministic. It reports runtime/database health, admitted workspace state, the state of the already-available structural index, aggregate Contract availability/current-drift state, work/assurance counts, warnings, and a bounded list of top-level folders.

It does not run an LLM, create canonical state, admit discovered candidates, trigger a structural scan, or expose Contract bodies, Evidence payloads, internal entity/turn/actor identifiers, or hashes. Folder information reuses the current process-local SIM/1 cache when that cache already exists. Contract drift comparison reads only workspace-bound Contract representations and discards content after comparison.

The detailed technical status and query surfaces remain available when explicitly requested.
