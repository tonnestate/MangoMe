# MangoMe v0.3.21 — Agent-Proof Zero-Touch Runtime

This release is a narrow operability repair based on failures observed on a managed host.

## Runtime generation reconciliation

Managed MangoMe MCP processes from the same installation are classified as current, stale, or unknown.

- stale means the managed expected version no longer matches the current installation;
- current means it matches;
- unknown is reported but not changed automatically.

Startup and explicit repair reconcile stale managed generations so an old in-memory MCP cannot keep serving after the installation has moved forward.

Invariant:

```text
ONE MANAGED INSTALLATION
→ ONE ACTIVE MANGOME GENERATION
```

## Explicit task opt-out

MangoMe is not a universal execution dependency. If the current user explicitly says a task should run without MangoMe or that MangoMe is out of scope, the task must not be routed through MangoMe.

Invariant:

```text
FRAMEWORK_BLOCKED != TASK_BLOCKED
```

## Unchanged

WorkIdentity, MongoDB schema, assurance semantics, and the LOCAL_HOST trust model are unchanged.
