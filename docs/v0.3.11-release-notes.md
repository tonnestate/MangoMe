# MangoMe v0.3.11 — Structural Intelligence, Small Worker Surface, Graceful Cognition

Release date: 2026-09-29

v0.3.11 is deliberately bounded to four changes: Structural Intelligence, normal-worker tool-surface reduction, a weak-agent semantic bridge, and graceful cognitive degradation. It does not introduce the planned cryptographic canonical-history chain, full bitemporal conflict arbitration, or a new cross-agent transport stack.

## Structural Intelligence / SIM/1

- Adds lazy, revision-bound structural observation with explicit provenance and confidence.
- Reuses RepoMap principles: definitions/references, file dependency graph, centrality, task-conditioned ranking, incremental caching, and bounded projection.
- Uses Python AST for Python and Tree-sitter for supported non-Python languages, with a bounded text fallback.
- Exposes six structural capabilities behind the semantic facade: status, search, symbol lookup, symbol relations, structural context, and impact frontier.
- Performs no full structural scan during bootstrap or ordinary status.
- Keeps the map derived and disposable: no canonical truth, Evidence, Assurance, authority, WorkIdentity, or normative-baseline mutation.

## Small semantic worker facade

The default `mangome-mcp` entry point now exposes exactly seven tools: status, observe, query, work, effect, verify, and control. Their sub-operations are typed enums so weak workers receive a constrained operation schema rather than dozens of top-level tool choices.

The previous detailed MCP surface is retained unchanged as `mangome-mcp-advanced`. v0.3.10c callers that explicitly import `mangome.mcp_server` therefore keep the precise capabilities; they are no longer the default worker surface.

## Weak-agent guidance

Every facade response carries:

- `disposition`
- `recommended_next_action`
- `allowed_next_actions`
- `forbidden_next_actions`
- `reason_codes`

Unsupported or invalid operations are blocked with repair/escalation guidance instead of requiring the worker to infer MangoMe internals.

## Graceful degradation

The release applies the rule: **fail closed on truth/effect mutation; degrade gracefully on cognition**.

- Structural failure returns `STRUCTURAL_CONTEXT_UNAVAILABLE` and remains non-blocking.
- Context-budget pressure first removes optional structural context, then uses the existing bounded compiler reductions, then falls back to minimal viable canonical context before `CONTEXT_UNAVAILABLE`.
- PCH may use structural relevance only for residency/relevance.
- SRA may use structural impact only as inspection candidates; the audit mutation boundary never expands from the map.
- Existing WorkIdentity, restore, effect-journal, verifier, controller/router, and owner-approval gates remain authoritative.

## Packaging

- Package version: `0.3.11`
- Normal CLI: `mangome = mangome.worker_cli:main` (managed setup/doctor target the worker facade)
- Advanced CLI: `mangome-advanced = mangome.cli:main`
- Default executable: `mangome-mcp = mangome.worker_mcp_server:main`
- Advanced executable: `mangome-mcp-advanced = mangome.mcp_server:main`
- Added runtime dependencies: `tree-sitter` and `tree-sitter-language-pack`

## Upgrade note

Managed client configuration is external deployment state. Existing v0.3.10c client entries may still invoke `python -m mangome.mcp_server`; after installing v0.3.11, rerun `mangome setup --client auto` or `mangome doctor --repair` so the normal client binding points to `mangome.worker_mcp_server`.
